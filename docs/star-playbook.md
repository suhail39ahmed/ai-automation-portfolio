# Star playbook (honest growth)

No fake stars, bots, or purchased engagement. Goal: get the right people to **clone → `make demo` → star if useful**.

## Pin order (GitHub profile)

Pin these six (or fewer if profile limit):

1. **ai-automation-portfolio** — hub / roadmap  
2. **kc-mcp** — flagship launch  
3. **ado-pipeline-doctor** — DevOps SA hook  
4. **foundry-eval-gate** — CI / quality hook  
5. **iac-guard-mcp** — security / platform hook  
6. **azure-ops-mcp** or **lakehouse-insights-skill** — rotate by audience that week  

Update the profile README snippet (`PROFILE_README_SNIPPET.md`) when pins change.

One primary post per week. Mid-week: one reply or comment on someone else's relevant post with a *concrete* demo tip (not a spam link dump).

## Communities (participate, don't spray)

Good fits (share only when you can answer questions):

- LinkedIn: Azure AI / MCP / DevOps Solution Architect circles you already belong to  
- GitHub Discussions / issues on MCP and Azure samples — help first, link second  
- Local SG meetups / user groups — demo live with `make demo`  
- Relevant Discord/Slack (Cursor, Azure) — follow each community's self-promo rules  

Avoid: mass tag influencers, identical comments across 20 threads, "please star" spam.

## Non-spam post checklist

- [ ] Lead with a problem you hit as an SA, not "excited to announce"  
- [ ] Show a runnable path (`make demo`) in the first screen of video  
- [ ] State what it is **not** (no hosted SaaS / auto-heal / fake prod claims)  
- [ ] One primary link; portfolio hub as secondary  
- [ ] First comment: exact clone + `make demo` commands (see `video-ideas.md`)  
- [ ] Reply to every thoughtful comment within 24h  
- [ ] Never invent star counts, download numbers, or "used by X enterprises"

## Metrics you *can* track privately

- Clone → `make demo` success (your own CI / friend tests)  
- Issues filed by strangers  
- Stars from people you recognize in the SA / Azure community  

Do not publish vanity counters you cannot verify.
